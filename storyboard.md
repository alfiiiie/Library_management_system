# Library Management System - Storyboard

## Problem
Students waste time searching for books and tracking due dates manually. The Library Management System helps users search, issue and return books easily.

## Story 1 - Student Registration
**User Action:** Student creates an account.
**System Response:** The system stores the student's details.
**Progress:** Completed

## Story 2 - Search Book
**User Action:** Student searches a book by title or author.
**System Response:** The system displays matching books and availability.
**Progress:** Completed

## Story 3 - Issue Book
**User Action:** Student requests to borrow a book.
**System Response:** The system records the issue date and due date.
**Progress:** In Progress

## Story 4 - Return Book and Fine
**User Action:** Student returns a book.
**System Response:** The system updates availability and calculates any fine.
**Progress:** To Do

## Story 5 - Borrowing History
**User Action:** Student opens borrowing history.
**System Response:** The system displays previously issued books.
**Progress:** To Do
